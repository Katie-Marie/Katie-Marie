# Katie-Marie Enlow

Hi! I'm Katie-Marie Enlow, a native Android developer in New Zealand, working on precision agriculture software. It runs on tablets mounted in agricultural vehicles and aircraft, and controls the spray and spread equipment they carry.

That splits into two halves. One is ordinary Android: Kotlin, Room, coroutines, and the long migration of a View Binding codebase to Jetpack Compose. The other is the wired-up half, where the tablet is plugged into rate controllers, GPS receivers and load cells over USB serial/CAN bus.

My site is at [katie-marie.github.io](https://katie-marie.github.io). I write notes on both in [android-notes](https://katie-marie.github.io/android-notes/). They started as notes to myself and are public in case they're useful to someone else.

### Things I work with

Kotlin, Jetpack Compose, View Binding, Room and SQLite migrations, coroutines and Flow, USB serial/CAN bus, and a rack of real Android tablets I use for automated testing.
